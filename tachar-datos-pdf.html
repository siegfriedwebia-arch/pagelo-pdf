Tachar datos de un PDF

Oculta tu DNI, número de cuenta, teléfono o dirección antes de enviar un documento. El texto tachado desaparece de verdad.

Buscar y tachar

También puedes arrastrar sobre la página para tachar a mano. Toca una zona negra para quitarla.

Las páginas con zonas tachadas se guardan como imagen: así el texto de debajo se borra de verdad y no se puede copiar ni recuperar. Revisa todas las páginas antes de enviar el documento.

Cómo se usa

  1. Sube el PDF.
  2. Pulsa «Buscar y tachar» para ocultar DNI, cuentas y otros datos automáticamente.
  3. Revisa las páginas y tacha a mano lo que falte arrastrando sobre el documento.
  4. Pulsa «Tachar y descargar».

Preguntas frecuentes

¿Se suben mis archivos a algún servidor?

No. Todo el proceso ocurre en tu navegador: tus documentos no salen de tu dispositivo y nadie más puede verlos.

¿Es seguro? ¿No se puede quitar el recuadro negro?

No se puede quitar: las páginas tachadas se convierten en imagen y el texto original desaparece. Poner un recuadro negro con otros programas a veces deja el texto debajo, que se puede copiar.

¿Encuentra todo automáticamente?

Encuentra los datos que están escritos como texto. En PDF escaneados o con formatos poco habituales puede fallar, así que revisa siempre el documento y tacha a mano lo que falte.
