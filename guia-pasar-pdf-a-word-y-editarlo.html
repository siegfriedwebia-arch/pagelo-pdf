Cómo pasar un PDF a Word para editarlo

Convierte un PDF en un documento de Word editable, qué se conserva y qué no, y qué hacer si el PDF es escaneado.

El PDF está pensado para que un documento se vea igual en cualquier sitio, no para editarlo. Cuando necesitas cambiar un párrafo, actualizar una fecha o reutilizar el texto, lo más práctico es pasarlo a Word.

Primero: ¿tu PDF tiene texto o es una imagen?

Abre el PDF e intenta seleccionar una palabra con el ratón o el dedo. Si puedes, el PDF tiene texto y se convertirá bien. Si no puedes seleccionar nada, es un documento escaneado: cada página es una foto, y antes hay que reconocer el texto con OCR.

PDF con texto: paso a paso

  1. Abre la herramienta PDF a Word y elige el archivo.
  2. Deja la opción «Texto editable».
  3. Pulsa «Convertir a Word» y descarga el archivo .docx.
  4. Ábrelo con Word, Google Docs o LibreOffice y edítalo como cualquier documento.
PDF → DOCXPDF a WordConvierte un PDF en un documento de Word editable.

Qué se conserva y qué no

Se conservan el texto, los títulos, los párrafos, las negritas y las listas. El diseño se simplifica: las columnas, las tablas complejas y las imágenes no se copian. Es lo normal en casi todos los conversores: un PDF no guarda la estructura de un documento de Word, solo dónde va cada letra.

Si lo que necesitas es que se vea exactamente igual, usa la opción «Aspecto exacto»: cada página se inserta como imagen en el Word. Se verá idéntico, pero no podrás editar el texto.

PDF escaneado: primero OCR

  1. Pasa el PDF por la herramienta OCR y elige «El texto para copiarlo».
  2. Copia el texto reconocido y pégalo en un documento nuevo de Word.
  3. Revísalo: el OCR puede confundir alguna letra, sobre todo si la imagen no es nítida.
OCROCR: PDF escaneado a textoReconoce el texto de escaneos y fotos para copiarlo o buscarlo.

Consejo: ¿Solo necesitas cambiar una fecha o un nombre? No hace falta pasar a Word: con Editar PDF puedes tapar el texto con corrector blanco y escribir el nuevo encima.
