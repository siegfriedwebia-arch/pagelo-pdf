How to convert a PDF to Word to edit it

Turn a PDF into an editable Word document, what's kept and what isn't, and what to do if the PDF is scanned.

PDFs are designed to look the same everywhere, not to be edited. When you need to change a paragraph, update a date or reuse the text, the most practical option is to convert it to Word.

First: does your PDF contain text or is it an image?

Open the PDF and try to select a word with your mouse or finger. If you can, the PDF contains text and will convert well. If you can't select anything, it's a scanned document: each page is a photo, and the text has to be recognized with OCR first.

PDF with text: step by step

  1. Open the PDF to Word tool and choose the file.
  2. Keep the “Editable text” option.
  3. Click “Convert to Word” and download the .docx file.
  4. Open it with Word, Google Docs or LibreOffice and edit it like any document.
PDF → DOCXPDF to WordTurn a PDF into an editable Word document.

What's kept and what isn't

Text, headings, paragraphs, bold and lists are kept. The layout is simplified: columns, complex tables and images aren't copied. That's normal for almost every converter: a PDF doesn't store a Word document's structure, only where each letter goes.

If you need it to look exactly the same, use the “Exact layout” option: each page is inserted into Word as an image. It will look identical, but you won't be able to edit the text.

Scanned PDF: OCR first

  1. Run the PDF through the OCR tool and choose “The text, to copy it”.
  2. Copy the recognized text and paste it into a new Word document.
  3. Check it: OCR can mix up a letter here and there, especially if the image isn't sharp.
OCROCR: scanned PDF to textRecognize text in scans and photos so you can copy or search it.

Tip: Only need to change a date or a name? No need to convert to Word: with Edit PDF you can cover the text with white-out and type the new text on top.
